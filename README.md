Sistema de gestion de inventario - buloneria

Hola soy enzo Nahuel mealla soy estudiante de la tecnicatura universitaria en programacion
de la UTN.

Este proyecto consiste en una aplicacion de escritorio desarrollada en java utilizando JavaFX
para la gestion integral de un inventario de buloneria. El sistema permite realizar operaciones CRUD,
filtrado avanzado mediante Streams y persistencia de datos en multiples formatos.

Caracteristicas principales

Gestion de productos: alta, baja y modificacion de bulones tuercas y arandelas utilizando una
estructura de herencia y clases abstractas.

Persistencia polimorfica: Capacidad de guardar JSON, CSV y binario.

Implementacion de filtros y ordenamientos dinamicos por precio, stock y tratamiento superficial mediante
Streams y lambdas.

Interfaz grafica (GUI): Entorno interactivo con tablas dinamicas, validacion de formularios
y cuadros de dialogo para el usuario.
